Python

Python is a popular language for scientific computing and is also well-suited for general programming tasks. To manage packages conveniently, we use conda, a package and environment manager. We install conda via Miniforge – a minimal distribution that comes pre-configured to use conda-forge as its default package source. conda-forge is a community-maintained repository with a wide selection of scientific packages.

Please ensure you install a Python version >= 3.9 (e.g., 3.11 is fine, 3.6 is not).

We will teach Python using JupyterLab, a programming environment that runs in your web browser (JupyterLab will be installed by Miniforge as part of the Carpentries environment). For this to work you will need an up-to-date browser.

Two installation steps at a glance

The installation consists of two parts:

  1. Install Miniforge – this gives you access to conda as a package and environment manager.
  2. Set up a conda environment – an isolated Python installation containing exactly the packages we need for the workshop, including JupyterLab. The packages are defined in the Carpentries environment file (carpentries_environment.yml). You do not need to install JupyterLab separately. You can view the file at any time here: carpentries_environment.yml

Before you start: Issues with OneDrive
OneDrive is used by many institutions to sync your user folder (C:\Users\[Your-Username]\). It can cause problems when installing the Carpentries environment.
If OneDrive is set up, make sure you can access your C:\Users\[Your-Username]\Downloads folder:

  • Open File Explorer
  • Right-click on the "Downloads" folder in the left navigation pane
  • Select "Properties"
  • In the "Location" tab, ensure the path is set to C:\Users\[Your-Username]\Downloads

If you encounter problems, please contact us before the course.
  1. Open https://conda-forge.org/download/ in your web browser.
  2. Download the Miniforge installer for Windows.
  3. Double-click the downloaded file (e.g., Miniforge3-Windows-x86_64.exe).
    • If a "Windows protected your PC" popup appears, click "More info" and select "Run anyway".
  4. Follow the installer with all default settings, except: check the box for Add Miniforge3 to my PATH environment variable.
  5. Right click the following link and click "Save link as...": Carpentries environment file
    • Save the file to C:\Users\[Your-Username]\Downloads.
    • Ensure the filename is carpentries_environment.yml and the "Save as type" option is set to YML file (*.yml).
    • The following steps require using the Miniforge Prompt. If you do not want to perform the installation yourself, stop here and ask for help during the tech check.
  6. Open the Start menu from your taskbar, or press the Win key.
  7. Search for the application "Miniforge Prompt" and click the icon to open it.
    • Make sure the prompt shows your folder C:\Users\[Your-Username]. If so, continue to Step 8 below.
    • If it doesn't:
      • Type whoami and press Enter. Your username will be shown as [ComputerName]\[Your-Username]. You only need the [Your-Username] part after the slash.
      • Type cd C:\Users\[Your-Username] and press Enter.
    • If you have difficulties, please contact us during the tech check.
  8. In the Miniforge Prompt window, run the following commands:
    • Type cd Downloads and press Enter
    • Type conda env create -f carpentries_environment.yml and press Enter
    This command reads the environment file and installs all required packages, including JupyterLab. Depending on your internet connection, this may take a few minutes.
  9. Once the installation is complete, you can close the Miniforge Prompt window.
  1. Open https://conda-forge.org/download/ in your web browser.
  2. Download the appropriate Miniforge installer for macOS.
    The following steps require using the Terminal. If you do not want to perform the installation yourself, stop here and ask for help during the tech check.
  3. Open a Terminal window and navigate to the Downloads folder (e.g., cd ~/Downloads).
  4. Type 
    bash Miniforge3-
    and then press Tab to autocomplete the full file name. The name of the file you just downloaded should appear. Press Enter (or Return depending on your keyboard).
  5. Follow the text-only prompts in the Terminal:
    • Type yes and press Enter (or Return) to confirm the license.
    • Press Enter (or Return) to confirm the default installation path.
    • Type yes and press Enter (or Return) to add Miniforge to your PATH.
  6. Close and restart your terminal.
  7. Right click the following link and click "Save link as...": Carpentries environment file
    • Save the file in the Downloads folder as carpentries_environment.yml ("Save as type": YML file (*.yml)).
  8. In the Terminal, run: conda env create -f ~/Downloads/carpentries_environment.yml. This command reads the environment file and installs all required packages, including JupyterLab. Depending on your internet connection, this may take a few minutes.
  9. Once the installation is complete, you can close the Terminal window.
